# Mobile money logos

Put the official logos here, using these exact file names. The Wi-Fi page shows them under the phone number box:

| File | Network |
|---|---|
| `mpesa.svg` | M-Pesa (Vodacom) |
| `mixx.svg` | Mixx by Yas |
| `airtel.svg` | Airtel Money |
| `halopesa.svg` | HaloPesa (Halotel) |

Use the files from each network's official brand kit, or the "accepted here" marks your payment provider (incpesa or Snippe) gives merchants. Follow their brand guidelines. If a file is missing, the page shows the network's name instead.
